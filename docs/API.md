# API 명세서

## 1. 인증

### 회원가입

**POST** `/auth/signup`

이메일, 비밀번호, 이름, 전화번호를 입력하여 회원가입합니다.

- 이메일 중복 검사
- 비밀번호 BCrypt 암호화 후 저장

---

### 로그인

**POST** `/auth/login`

이메일과 비밀번호를 검증하고 Access Token을 발급합니다.

---

### 내 정보 조회

**GET** `/auth/me`

로그인 시 발급받은 Access Token을 이용하여 현재 로그인한 사용자의 정보를 조회합니다.

---

## 2. 상품

### 상품 목록 조회

**GET** `/api/products`

상품 목록을 조회합니다.

- 카테고리 필터
- 최소 / 최대 가격 필터
- 페이지네이션
- 최신순 정렬
- 재고가 0인 상품은 품절 상태로 표시

---

### 상품 상세 조회

**GET** `/api/products/{productId}`

선택한 상품의 상세 정보를 조회합니다.

존재하지 않는 상품 ID로 요청할 경우 `404 Not Found`를 반환합니다.

---

## 3. 장바구니

### 장바구니 조회

**GET** `/api/carts`

현재 로그인한 사용자의 장바구니를 조회합니다.

조회 결과에는 다음 정보가 포함됩니다.

- 장바구니 상품 목록
- 상품 ID
- 상품명
- 가격
- 수량
- 전체 상품 금액

---

### 상품 담기

**POST** `/api/carts/{productId}`

선택한 상품을 장바구니에 담습니다.

**Request**

```json
{
  "quantity": 5
}
```

동일한 상품을 다시 담을 경우 기존 장바구니 상품의 수량을 증가시킵니다.

재고보다 많은 수량을 요청할 경우 오류를 반환합니다.

---

### 장바구니 상품 수량 변경

**PATCH** `/api/carts/cartItems/{cartItemId}`

장바구니에 담긴 상품의 수량을 변경합니다.

변경하려는 수량이 현재 재고를 초과할 경우 오류를 반환합니다.

---

### 장바구니 상품 삭제

**DELETE** `/api/carts/cartItems/{cartItemId}`

장바구니에 담긴 특정 상품을 삭제합니다.

**Response**

`204 No Content`

---

### 장바구니 전체 삭제

**DELETE** `/api/carts/cartItems`

현재 장바구니에 담긴 모든 상품을 삭제합니다.

**Response**

`204 No Content`

---

## 4. 주문

### 주문 미리보기

**GET** `/api/orders/checkout`

결제하기 전 주문할 상품과 총 금액을 미리 조회합니다.

선택한 장바구니 상품만 주문할 수도 있으며,
`cartItem`을 지정하지 않을 경우 장바구니 전체 상품을 대상으로 합니다.

**Example**

`/api/orders/checkout?cartItem=1&cartItem=2`

---

### 주문 생성

**POST** `/api/orders`

장바구니 상품을 기준으로 주문을 생성합니다.

주문 생성 과정에서 다음 작업을 수행합니다.

1. 주문 상품 확인
2. 재고 차감
3. 주문 생성
4. 주문 상품 생성
5. 결제 정보 생성
6. 결제 대기 상태로 설정

**Request**

```json
{
  "cartItemIds": [1, 2]
}
```

---

### 내 주문 목록 조회

**GET** `/api/orders?page=&size=`

현재 로그인한 사용자의 주문 목록을 최신순으로 조회합니다.

페이지네이션을 지원합니다.

---

### 주문 상세 조회

**GET** `/api/orders/{orderId}`

선택한 주문의 상세 정보를 조회합니다.

다음 정보를 함께 반환합니다.

- 주문 정보
- 주문 상품 목록
- 상품명 Snapshot
- 주문 당시 가격 Snapshot
- 주문 수량
- 결제 상태

---

### 주문 취소

**POST** `/api/orders/{orderId}/cancel`

주문을 취소합니다.

주문 취소 시 다음 작업을 수행합니다.

- 주문 상태 변경
- 결제 상태 변경
- 주문 상품의 재고 복구

이미 완료된 주문은 취소할 수 없으며,
이미 취소된 주문도 다시 취소할 수 없습니다.

---

## 5. 결제

### 모의 결제 승인

**POST** `/api/payments/confirm`

주문에 대한 모의 결제를 승인합니다.

결제 요청 시 다음 내용을 검증합니다.

- 주문 소유권 확인
- 결제 상태 확인
- 주문 상태 확인
- 결제 금액 검증

### 결제 성공

결제 결과가 `SUCCESS`인 경우

1. 결제 상태 → 완료
2. 주문 상태 → 주문 완료
3. 장바구니 상품 삭제

---

### 결제 실패

결제 결과가 `FAIL`인 경우

1. 결제 상태 → 실패
2. 주문 상태 → 주문 취소
3. 선차감한 상품 재고 복구
4. 장바구니 상품 유지

결제 실패 시 장바구니 상품을 유지하여
사용자가 다시 결제를 시도할 수 있도록 합니다.

---

### 결제 단건 조회

**GET** `/api/payments/{orderId}`

주문 ID를 기준으로 해당 주문의 결제 정보를 조회합니다.

주문 정보와 결제 정보의 존재 여부 및
결제 상태를 확인할 수 있습니다.
